DEPLOY ON NETLIFY
1. Unzip this file. You get a folder with index.html and netlify.toml.
2. netlify.com > Sites > "Add new site" > "Deploy manually" > drag the UNZIPPED FOLDER (or drag this zip).
3. Subscribers: after deploy, open Site > Forms > "subscribe" to see every visitor who subscribed (automatic).
4. In index.html change OWNER_PASSCODE from 'change-me'.
5. Post articles in Owner mode (footer), then "Export site data" and paste into the siteData block, then redeploy to publish for everyone.
